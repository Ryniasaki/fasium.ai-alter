# 常见问答

## 产品定位

**Q: Fasium 是什么？**
A: Fasium 是面向服装设计与商品企划的 AI 设计平台，将灵感生成、改款、试穿展示、资料整理集成到同一个工具中。

**Q: 适合谁使用？**
A: 设计师用它做灵感与方案，版师用它看工艺细节与技术图，商品团队做选款和对比，品牌团队做视觉提案和沟通。

**Q: 和传统设计软件的区别？**
A: 传统软件是"画图工具"，Fasium 是"设计加速器"——从想法到方案再到展示素材，整体流程更快。

## 功能使用

**Q: Redesign 支持几张图同时编辑？**
A: 支持最多 4 张图同时处理，便于做多方案对比。

**Q: 提示词怎么写效果最好？**
A: 先写款式和版型，再写材质与颜色，最后补充风格或场景。例如"短款夹克，羊毛，墨绿色，复古街头"。

**Q: 提取的花型能直接应用到新款吗？**
A: 可以，提取后可用于面料替换或新设计应用。

**Q: 文生服装更适合做概念探索还是可生产款？**
A: 两者都可以。概念探索更快，落地款建议配合后续细节修改和参考图。

**Q: 无缝花型适合哪些面料？**
A: 适合印花、针织、图案类面料，尤其是重复纹理。

**Q: Sheet 能生成哪些内容？**
A: 可以生成技术图、里布结构图、技术包和初步成本估算。

## 效果优化

**Q: 如何避免"跑偏"的结果？**
A: 用更明确的描述和参考图来控制方向。

**Q: 风格能保持一致吗？**
A: 可以通过统一关键词或参考图保持一致。

**Q: 如何减少随机性？**
A: 用清晰的描述、固定参考图和一致参数。

**Q: 画笔/橡皮怎么影响结果？**
A: 画笔标记要修改的区域，系统主要根据标记部分做改动。橡皮用于取消标记。

## 协作与分享

**Q: 可以分享结果给团队吗？**
A: 可以通过项目共享功能邀请团队成员，也可以导出图片。

**Q: 权限能控制到不同成员吗？**
A: 可以设置 viewer（查看）和 editor（编辑）不同权限。

**Q: Board/Project 主要用来做什么？**
A: 整理灵感、素材、生成结果和方案对比，支持拖拽排列和标注。

## 账号与积分

**Q: 新用户有多少初始积分？**
A: 默认 500 积分（管理员可配置）。

**Q: 不同功能消耗多少积分？**
A: 由管理员在 Admin 面板配置各工作流的积分费率。

**Q: 积分用完怎么办？**
A: 联系管理员获取积分兑换码，在 Admin 面板应用。

**Q: 提交反馈会奖励点数吗？**
A: 会。每次成功提交反馈奖励 500 点，每个自然月最多奖励 3 次；超过后仍可继续提交，但不再发点。

**Q: 管理员在哪里查看反馈？**
A: 管理员直接打开左侧的“反馈”路由，就能看到当前权限范围内的全部反馈记录。

## 体验与稳定性

**Q: 任务会排队吗？**
A: 高峰期可能需要排队，系统会显示进度状态。

**Q: 失败时会提示原因吗？**
A: 会显示错误信息。常见原因是提示词不清晰或参考图质量不佳。

**Q: 生成过程中能取消吗？**
A: 可以取消任务并重新提交。

**Q: 支持中文和英文吗？**
A: 支持中英文双语切换，在界面中可一键切换。

**Q: 有暗色模式吗？**
A: 有，在设置中可切换亮色/暗色主题。
