# 用户使用指南

## 注册与登录

1. 访问首页，点击「注册」
2. 填写用户名和密码（邮箱可选）
3. 注册成功后自动分配初始积分
4. 使用用户名和密码登录

## 改款 (Redesign)

**场景：** 对已有款式做局部修改（改领型、换面料、改细节等）

1. 进入 `/redesign` 页面
2. 上传参考图片（最多 4 张）
3. 使用画笔标记需要修改的区域
4. 输入提示词描述想要的变化（如"改为立领，使用丝绸面料"）
5. 点击生成，等待结果
6. 查看多个生成版本，选择满意的结果

**技巧：**
- 画笔标记越精确，修改区域越准确
- 提示词同时描述材质和廓形效果更好
- 结果可保存到项目，也可继续迭代修改

## 花型提取 (Extract)

**场景：** 从服装/模特图中提取花型、纹理、图案

1. 进入 `/extract` 页面
2. 上传包含花型的服装图片
3. 点击「提取」
4. 查看提取的花型结果

条纹和格纹可使用专用页面 `/extract_plaid`、`/extract_stripe` 获得更好效果。

## 文生服装 (Text-to-Cloth)

**场景：** 通过文字描述快速生成设计方案

1. 进入 `/text_to_cloth` 页面
2. 输入描述词，格式建议：款式 + 材质 + 颜色 + 风格
   - 例如："短款夹克，羊毛，墨绿色，复古街头"
3. 选择生成数量
4. 点击生成

## 虚拟试衣 (Try-on)

**场景：** 生成模特试穿效果图

1. 进入 `/try-on` 页面
2. 上传服装平铺图
3. 选择模特类型
4. 生成试穿效果

## 无缝花型 (Seamless Patterns)

**场景：** 生成可重复拼接的面料图案

1. 进入 `/seamless-patterns` 页面
2. 上传参考花型或图片
3. 生成无缝拼接版本

## 配色对比 (Variants)

**场景：** 同款式做不同配色/面料对比

1. 进入 `/variants` 页面
2. 上传基础款图片
3. 设定配色或面料变化
4. 一次生成多组对比结果

## 设计画板 (Board)

**场景：** 整理灵感、素材和生成结果

1. 进入 `/board` 页面
2. 将图片拖入画板
3. 自由排列、标注说明
4. 可导出或分享给团队

## 项目管理 (Project)

1. 创建项目，将相关任务归到同一项目下
2. 支持团队成员邀请和权限管理
3. 项目可分享给协作者

## 任务记录

1. 进入 `/tasks-record` 页面
2. 按时间或类型筛选历史任务
3. 查看当时的输入参数和生成结果
4. 可复用参数重新生成

## 工艺单 (Sheet)

1. 进入 `/sheet` 页面
2. 输入服装信息或上传参考图
3. AI 生成技术图、里布图、技术包或成本估算

## 其他工具

| 工具 | 入口 | 说明 |
|------|------|------|
| 背景移除 | `/remove_background` | 一键抠图 |
| 超分辨率 | `/hi_res` | 放大并提升清晰度 |
| SVG 矢量化 | `/svg` | 将位图转为矢量 |
| 视频生成 | `/video-generation` | 从静态图生成展示视频 |
| AI 助手 | `/chatbot` | 智能对话辅助设计 |

## 推荐工作流

从灵感到成品的推荐路径：

1. **Text-to-Cloth** — 输入关键词，快速出方向
2. **Redesign** — 对满意的方向做细节修改
3. **Extract** — 提取需要的花型/纹理
4. **Variants** — 做配色或面料对比
5. **Try-on** — 生成模特试穿图
6. **Hi-Res** — 提升最终图片清晰度
7. **Sheet** — 生成工艺单和技术资料
