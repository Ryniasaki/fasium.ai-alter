## 开发目的
通过可视化的 AI 服装设计工作台整合改图、花型提取、虚拟试穿、档案打包等工具，帮助服装企业在一个 Web 平台中完成从创意、设计、打样到交付的协同流程，提高设计与采购效率。

## 面向领域 / 行业
面向时尚与服装产业链（设计工作室、面料供应商、电商买手团队等），用于数字化的款式研发、印花管理及企划协作。

## 软件的主要功能（200 字内）
1. 设计提案：`app/tools`、`lib/tools-catalog.ts` 提供“改图”“花型衍生”“虚拟试穿”等 AI 工具卡片，并按工作流分类筛选。
2. 结构提取：/extract、/extract_plaid、/extract_stripe 页面结合 API 客户端（lib/extract-api-client.ts）实现纹理拆解、条纹提取与重复花型重建。
3. 展示输出：/hi_res、/remove_background、/svg、/video-generation 模块提供高清增强、抠图、矢量化、走秀视频生成等素材处理能力。
4. 生产协同：/sheet、/project、/tasks-record 支持设计档案打包、项目协同与任务状态追踪（lib/redesign-api-client.ts、lib/task-activity.ts）。
5. Workspace 导航：components/navigation.tsx 提供响应式侧边栏、任务侧板、权限控制以及移动端菜单，统一入口开启上述工具。

## 软件的技术特点（100 字内）
- 基于 Next.js 14 + React 19 + TypeScript 5 的前后端一体化框架，支持 SSR/SPA 自适应。
- Tailwind CSS + Radix UI 组合实现主题化、响应式界面，配合 Framer Motion 呈现任务/菜单动画。
- 多 API 客户端（lib/api-client.ts、lib/redesign-api-client.ts、lib/text-to-image-api-client.ts 等）抽象与后端服务通讯，统一错误处理与任务事件广播。
- 工具目录数据（lib/tools-catalog.ts）结构化描述功能/分类/状态，便于动态渲染和扩展。
